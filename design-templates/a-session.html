Checkpoints and revert

Every file write takes a snapshot first. Snapshots are content-addressed, so ten edits to the same file cost one copy. Revert walks the conversation back, restores each file to its first pre-change state, and records the undo as an append-only entry instead of rewriting history.

snapshot before write, hash-deduplicated
multi-file renames restore file by file
works across sub-agents and after summarization

Context summarization

The agent projects context usage before tool results land, not after. When it crosses a threshold it compacts the session into a task-oriented summary, reusing the prompt cache so compaction costs close to a normal turn.

Large tool output handling

A 50k-character test log used to flood the context window. Now oversized output goes to a session file and the model sees the head, the tail, and a path it can grep. Per-response context drops from tens of thousands of characters to about one thousand.
